# C Community Simulator

C 언어로 자료구조를 학습하고, 직접 구현한 C 코어와 raylib UI를 연결하는 로컬 커뮤니티 시뮬레이터입니다.

이 프로젝트는 실제 네트워크 커뮤니티 서비스가 아닙니다. 단일 PC에서 회원가입·로그인 후 글, 계층형 댓글, 좋아요/싫어요, 제목 검색을 사용하는 과정을 통해 C의 동적 메모리와 자료구조를 실제 화면 기능에 적용합니다.

## 목표

### 학습 목표

- C 구조체, 포인터, 동적 메모리 할당과 해제를 직접 다룹니다.
- 동적 배열, 댓글 트리, 탐색, 정렬을 구현하고 사용 이유를 설명합니다.
- 정상·경계·실패 경로를 테스트하고 시간·공간 복잡도를 기록합니다.

### 프로젝트 목표

- raylib 기반 로컬 데스크톱 화면을 제공합니다.
- 회원가입, 로그인, 로그아웃, 프로필 수정·탈퇴를 지원합니다.
- 글과 댓글/대댓글의 CRUD를 작성자 권한으로 처리합니다.
- 좋아요/싫어요의 상태 변경과 집계를 제공합니다.
- 제목 부분검색, 정렬, CSV 저장·불러오기를 지원합니다.

## MVP 업무 규칙

- 아이디는 중복될 수 없습니다.
- 글과 댓글은 작성자만 수정·삭제할 수 있습니다.
- 회원 탈퇴는 WITHDRAWN 상태로 처리하며 기존 작성자는 탈퇴 회원으로 표시합니다.
- 글 삭제 시 연결된 댓글과 반응을 함께 삭제합니다.
- 대댓글이 있는 댓글을 삭제하면 '삭제된 댓글입니다.'로 표시합니다.
- 반응은 NONE에서 LIKE 또는 DISLIKE로 시작하며, LIKE와 DISLIKE 간 변경은 가능하지만 취소는 불가합니다.
- 글과 댓글은 한 줄 텍스트만 허용하며 줄바꿈과 쉼표를 금지합니다.

## 화면 흐름

~~~text
로그인 ↔ 회원가입
  ↓
글 목록(최신순·제목 검색) → 글 상세 → 글/댓글/대댓글 CRUD, 반응
  ↓
프로필 수정·탈퇴 → 로그아웃
~~~

## 핵심 자료구조

| 자료구조/개념 | 적용 |
|---|---|
| 동적 배열 | 회원·글·댓글·반응 목록 |
| 부모 ID 기반 트리 | 댓글과 한 단계 대댓글 |
| 선형 탐색 | 아이디 중복 검사, ID 탐색, 제목 부분검색 |
| 정렬 | 최신순·반응 순 글 목록 |
| 힙/우선순위 큐 | 인기 글 Top N 확장 |

스택·큐·일반 그래프, 투표, Unity Engine 연동은 8/30 MVP 이후의 2차 확장입니다.

## 프로젝트 구조

~~~text
include/  공개 구조체와 함수 선언
src/      C 코어와 raylib UI 구현
tests/    assert 기반 모듈 테스트
data/     버전 관리하는 샘플 CSV
docs/
  learning/  학습 로드맵과 기록
  project/   WBS와 설계 문서
~~~

## 개발 환경

| 항목 | 사용 |
|---|---|
| OS | Windows |
| 언어 | C |
| 컴파일러 | GCC 또는 MSVC |
| 빌드 | CMake |
| UI | raylib |
| 저장 | CSV |

raylib와 CMake 설정이 추가된 뒤 실제 빌드 명령을 이 문서에 검증 결과와 함께 기록합니다. 아직 성공하지 않은 명령은 완료된 것처럼 적지 않습니다.

## 완료 기준

- raylib 앱과 C 코어가 빌드·실행됩니다.
- 회원가입·로그인·로그아웃과 회원 상태 관리가 동작합니다.
- 글과 계층형 댓글 CRUD, 반응, 제목 검색, 정렬이 동작합니다.
- CSV 저장 후 재실행해도 데이터 관계가 유지됩니다.
- 자료구조 적용 이유, 복잡도, 메모리 관리, 테스트 결과를 설명할 수 있습니다.
