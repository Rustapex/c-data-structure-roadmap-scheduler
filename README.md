# C Data Structure Roadmap Scheduler

C 언어로 자료구조를 학습하고, 학습/개발 작업의 선후행 관계를 분석하는 일정 추천 CLI 프로젝트입니다.

이 저장소는 단순히 C 코드를 작성하는 저장소가 아니라, 자료구조 수업 전 주요 개념을 한 바퀴 학습하고 이를 실제 프로젝트 기능에 적용하는 과정을 기록하기 위한 저장소입니다.

## 목표

### 학습 목표

- C 언어 기본 문법을 복습한다.
- 포인터, 구조체, 동적 메모리 할당을 다시 익힌다.
- 배열, 연결리스트, 스택, 큐, 트리, 그래프, 정렬을 직접 구현한다.
- 각 자료구조의 시간복잡도와 공간복잡도를 정리한다.
- 자료구조가 실제 기능에서 왜 필요한지 설명할 수 있게 만든다.

### 프로젝트 목표

- 작업과 학습 일정을 C 기반 CLI 프로그램으로 관리한다.
- 작업 간 선후행 관계를 그래프로 표현한다.
- 순환 의존성을 탐지한다.
- 위상 정렬을 활용해 가능한 작업 순서를 계산한다.
- 우선순위 큐를 활용해 오늘 해야 할 작업을 추천한다.
- CSV 파일을 이용해 데이터를 저장하고 불러온다.

## 프로젝트 주제

### C-DS Roadmap Scheduler

사용자가 작업, 예상 소요 시간, 마감일, 우선순위, 선행 작업 관계를 입력하면 프로그램이 가능한 작업 순서와 오늘 해야 할 작업을 추천합니다.

예상 실행 흐름은 다음과 같습니다.

```text
1. 작업 추가
2. 작업 목록 조회
3. 작업 의존성 추가
4. 순환 의존성 검사
5. 가능한 작업 순서 계산
6. 오늘 할 일 추천
7. CSV 저장
8. CSV 불러오기
9. 종료
```

## 핵심 자료구조

| 자료구조 | 프로젝트 적용 |
|---|---|
| 배열 / 동적 배열 | 작업 목록 저장 |
| 연결리스트 | 인접 리스트, 변경 이력 |
| 스택 | DFS, Undo 기능 후보 |
| 큐 | 위상 정렬 |
| 트리 | 학습 카테고리 구조 후보 |
| 그래프 | 작업 간 선후행 관계 |
| 힙 / 우선순위 큐 | 오늘 할 일 추천 |
| 정렬 | 마감일순, 우선순위순 정렬 |

## 빌드 및 실행

### 단일 파일 테스트

```powershell
gcc .\src\main.c -o roadmap_scheduler.exe
.\roadmap_scheduler.exe
```

### CMake 빌드

```powershell
cmake -S . -B build -G Ninja
cmake --build build
.\build\roadmap_scheduler.exe
```

## 완료 기준

이 프로젝트는 다음 조건을 만족하면 완료로 봅니다.

- C로 빌드 가능한 CLI 프로그램이 있다.
- 작업 추가/조회가 가능하다.
- 작업 의존성을 그래프로 표현할 수 있다.
- 순환 의존성을 감지할 수 있다.
- 위상 정렬로 가능한 작업 순서를 출력할 수 있다.
- 우선순위 기반 오늘 할 일을 추천할 수 있다.
- CSV로 저장/불러오기가 가능하다.
- 주요 자료구조의 적용 이유와 복잡도를 설명할 수 있다.
- README만 보고 프로젝트를 실행할 수 있다.
